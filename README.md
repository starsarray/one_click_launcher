# 一键启动 v0.4.12-demo

双击一个桌面快捷方式，即可同时打开预设的一组软件、文件、文件夹或网址。

## 使用

1. 运行 `one_click_launcher.pyw`，或双击桌面的“一键启动”。
2. 新建工作组。
3. 添加要启动的文件、软件、文件夹或网址。
4. 点击“创建桌面快捷方式”。
5. 以后双击该快捷方式即可直接启动这个工作组。

也可以点击“捕捉当前窗口”，然后在 3 秒内切换到目标软件。一键启动会优先保存该软件正在打开的文件或网址；WPS/Office 会尽量捕捉当前已打开的多个文档、表格、演示和 PDF，如果识别不到文件，就保存软件本身。

点击“捕捉全部窗口”会批量捕捉当前桌面上的可见窗口，多余项目可以之后手动删除。

启动项目列表每行左侧有“❌”，连续点击同一位置也可以连续删除项目。界面区域和按钮会随窗口大小自适应调整。

“捕捉规则”页可以创建规则组，并通过捕捉当前窗口、捕捉全部窗口或手动添加路径来生成规则。可以同时启用多个规则组，捕捉启动项目时会自动合并规则并跳过匹配的路径。

左侧的“创建本软件快捷方式”用于创建“一键启动”管理软件本身的桌面入口。

创建或删除快捷方式后，会通知系统刷新并向桌面窗口发送刷新命令。

配置只保存在本机程序目录中。
